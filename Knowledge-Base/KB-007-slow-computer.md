# KB-007: Slow Computer Troubleshooting

**Applies to:** Workstations reported as generally slow, sluggish, or freezing without a specific error message

## Symptom

User reports the computer is slower than usual, programs take longer to open, or the system freezes occasionally, with no specific error message pointing to a cause.

## Cause

Often a combination of factors rather than one clear cause: too many background processes, unnecessary programs launching at startup, low available disk space, or a combination of all three.

## Resolution Steps

1. Ask the user when the slowness started and whether anything changed recently, new software, updates, or anything unusual. This helps narrow down whether it's a new issue or a gradual buildup.
2. Check Task Manager for unusually high CPU, memory, or disk usage from background processes.
3. Check startup programs for anything unnecessary launching automatically at boot, and disable what isn't needed.
4. Check available disk space. Low free space can noticeably slow a system down.
5. Clear temporary files if disk space is low.
6. Ask the user to monitor performance for a day or so before closing, since some fixes (like freed disk space or reduced startup load) take a bit to show their full effect.

## Notes

If performance issues keep coming back after this kind of cleanup, it may point to a hardware limitation (low RAM, an aging hard drive) or malware, worth investigating further rather than repeating the same cleanup each time.
