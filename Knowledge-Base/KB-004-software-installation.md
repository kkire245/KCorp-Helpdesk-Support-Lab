# KB-004: Software Installation Requests

**Applies to:** Standard (non-admin) user accounts requesting new software

## Symptom

User needs a specific application but can't install it themselves due to standard, non-admin permissions on their workstation.

## Cause

Not a technical issue, this is expected behavior. Standard users are intentionally restricted from installing software to reduce security risk and maintain consistency across company machines.

## Resolution Steps

1. Verify the requester's identity and confirm the software fits a reasonable business need for their role.
2. Choose an appropriate, approved application. Prefer lightweight, well-known, free tools for simple needs (like PDF viewing) rather than defaulting to a heavier or paid product without reason.
3. Install the software on the user's workstation.
4. Open the application or a test file to confirm it works correctly before closing the ticket.
5. Let the user know the install is complete and confirm they don't need any further setup.

## Notes

If a request is for something unusual, unapproved, or expensive, it's worth checking with a manager or following whatever approval process the company has before installing, rather than fulfilling every request automatically.
