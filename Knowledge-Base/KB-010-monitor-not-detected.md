# KB-010: External Monitor Not Detected

**Applies to:** Laptops using a dock or cable connection to an external monitor

## Symptom

An external monitor that was previously working stops being detected, often after a laptop is unplugged and reconnected to a dock.

## Cause

Most commonly a loose or improperly seated cable connection, either at the dock or the monitor end, rather than a driver or software problem.

## Resolution Steps

1. Verify the user's identity before starting.
2. Have the user unplug and firmly reseat the cable connecting the laptop or dock to the monitor.
3. If that doesn't resolve it, try a different port on the dock, since a specific port can sometimes be the issue.
4. Check Device Manager for any driver errors or unrecognized display devices to rule out a software cause.
5. Confirm the monitor is detected and displaying correctly before closing the ticket.

## Notes

If this keeps happening to the same user or dock, it may point to a failing cable or dock port worth replacing, rather than something to keep re-troubleshooting each time.
